# Job Tracker

Local, single-user job application tracker. See [CLAUDE.md](./CLAUDE.md) for conventions, [SPEC.md](./SPEC.md) for the data model and screens, and [PLAN.md](./PLAN.md) for build order.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Data is stored locally in `data/app.db` (SQLite) and `data/uploads/` — not committed to git.
